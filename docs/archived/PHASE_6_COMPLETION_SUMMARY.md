## Operational Guidelines

### Running Benchmarks

**All benchmarks**:
```bash
pytest tests/performance/test_orm_vs_sql_benchmarks.py -v --benchmark-only
```

**Specific category**:
```bash
pytest tests/performance/test_orm_vs_sql_benchmarks.py::TestMetadataPerformance -v
```

**Generate reports**:
```bash
python -m scripts.generate_performance_baseline
```

### Monitoring During Rollout

**Key metrics** (via feature flags endpoint):
```bash
curl http://localhost:8000/api/v1/feature-flags/stats | jq
```

**Alert thresholds**:
- Error rate > 1% → Investigate
- Latency > 30% overhead → Optimize
- Memory > 50MB above baseline → Review

**Rollback procedure**:
```bash
export USE_ORM_GLOBAL=false
systemctl restart audiobooksync-api
```
